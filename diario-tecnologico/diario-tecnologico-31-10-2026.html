Anthropic API 2026-10-21: Breaking Changes que Impactam Qualquer Integração Java

A Anthropic publicou a versão 2026-10-21 da API com um conjunto de breaking changes que precisam de atenção imediata de qualquer time que integre com os modelos Claude. As mudanças mais críticas: na nova versão, requisições que enviam temperature, top_p ou top_k junto a determinados tipos de mensagem retornam erro 400. Além disso, o Admin API renomeou cinco campos de resposta e o Claude Enterprise Analytics API renomeou dois — os nomes antigos foram removidos sem período de deprecação gradual.

Há também boas notícias no pacote: o limite de tamanho de requisição nas APIs de Messages e Token Counting subiu de 32 MB para 128 MB, o que abre espaço para processamento de documentos maiores sem recorrer a chunking forçado. O dia 20 de outubro também trouxe Organization Webhooks em beta no Admin API e User Profiles — mudanças estruturais para quem gerencia workspaces corporativos.

Do ponto de vista prático: as integrações pinadas à versão antiga continuam funcionando. O problema começa quando você atualiza o SDK Java para a versão major mais recente, que por padrão envia a nova versão da API e passa a chave como Authorization: Bearer. Antes de qualquer atualização de dependência, leia o guia de migração oficial. Vale o tempo.

LangChain4j 1.23.0 Publicado; 1.22.0 Traz Prompt Caching Automático para Anthropic

Dois lançamentos relevantes na mesma semana para o ecossistema LangChain4j. O 1.22.0, publicado em 9 de outubro e já estável no Maven Central, entregou três capacidades que interessam diretamente a quem usa Java com LLMs: suporte à OpenAI Decisions API, inferência em lote via AWS Bedrock, e — o mais impactante — prompt caching automático para Anthropic. Isso significa que chamadas repetidas com prefixos de contexto similares passam a se beneficiar do cache da Anthropic sem que você precise instrumentar nada explicitamente.

Já o 1.23.0 foi publicado em 28 de outubro pelo Dmytro Liubarskyi via Open Collective, mas ainda pode não ter chegado ao Maven Central no momento que você lê isso. O repositório Maven lista 1.22.0 como versão mais recente. Se você trabalha com repositórios do GitHub Packages, já pode testar; caso contrário, aguarde a propagação para o Central antes de atualizar.

Um detalhe importante para quem usa Spring Boot starter com LangChain4j: o starter e o módulo de embeddings ainda estão na 1.22.0-beta32 — não existe versão estável dessas dependências ainda. Estruture seu projeto para isolar essas dependências beta e facilitar o upgrade quando a estabilização vier.

Agentic RAG Deixa de Ser Experimento e Vira Infraestrutura Enterprise

A Progress Software anunciou em 1º de outubro uma expansão relevante da sua plataforma de Agentic RAG: integração nativa com Microsoft Teams e plugin de ingestão para WordPress. A proposta é reduzir a necessidade de orquestração customizada — o agente responde com citação de fontes diretamente no canal do Teams. É um movimento que sinaliza a maturidade do conceito: quando uma plataforma enterprise embute RAG agnéstico como feature de produto, é porque o mercado parou de perguntar "para que serve" e começou a perguntar "como faço funcionar".

O contexto macro reforça isso: o Gartner projeta que 33% das aplicações enterprise incluirão Agentic AI até 2028, ante menos de 1% em 2024. O que me chama atenção não é o número em si — é a velocidade. Dois anos para sair de marginal para mainstream. Para quem está construindo plataformas Java hoje, isso significa que orquestração de agentes com acesso a base de conhecimento não é mais uma feature futura — é requisito de produto.

FinOps para IA: 98% das Equipes Gerenciam Custos de LLM em 2026

O relatório State of FinOps 2026 da FinOps Foundation aponta que 98% dos profissionais de FinOps agora gerenciam gastos com IA, em comparação com 63% em 2025 e apenas 31% em 2024. O crescimento reflete a realidade das contas: tokens custam dinheiro, e chamadas sem controle chegam fácil a centenas de dólares por dia em projetos com usuário real.

A tendência que me parece mais madura é a separação entre LLM Observability (traces, latência, avaliação de qualidade) e AI FinOps (custo por token, chargeback, forecasting). Plataformas como Finout, Vantage e Kosmoy estão resolvendo o lado financeiro, enquanto Datadog e similares focam no comportamento. Para projetos Java enterprise, o ponto de partida pragmático é instrumentar o custo por requisição já na camada de serviço antes de escolher uma plataforma — você precisa do dado para justificar a ferramenta.

☕ Radar Java + IA

Esta semana foi mais movimentada do que parece no título dos releases. O ponto de maior impacto prático para o ecossistema Java com IA está na combinação de dois fatores: o LangChain4j 1.22.0 com prompt caching automático para Anthropic, e a nova versão da API da Anthropic com breaking changes. Juntos, eles criam uma situação onde você quer os benefícios de custo do novo recurso, mas precisa navegar a migração com cuidado.

No LangChain4j, o estado atual das dependências para quem usa Maven é: core em 1.22.0 estável, Spring Boot starter e módulo de embeddings ainda em beta (1.22.0-beta32). A versão 1.23.0 foi publicada em 28 de outubro mas pode ainda não estar no Maven Central — verifique antes de declarar a dependência. O suporte a AWS Bedrock batch inference na 1.22.0 é especialmente útil para pipelines de ingestão offline em RAG, onde você processa documentos em lote sem necessidade de resposta síncrona.

Para quem está construindo pipeline RAG em Java com LangChain4j e MongoDB como embedding store, o ponto de atenção desta semana é garantir que a versão do driver MongoDB está alinhada com a versão do módulo LangChain4j — incompatibilidades de versão do driver têm sido a causa raiz de bugs sutis em produção que só aparecem sob carga.

// LangChain4j 1.22.0 — pom.xml snippet
// Verifique o Maven Central para a versão mais recente antes de usar

<dependency>
  <groupId>dev.langchain4j</groupId>
  <artifactId>langchain4j</artifactId>
  <version>1.22.0</version>
</dependency>

<!-- Spring Boot starter: ainda em beta -->
<dependency>
  <groupId>dev.langchain4j</groupId>
  <artifactId>langchain4j-spring-boot-starter</artifactId>
  <version>1.22.0-beta32</version>
</dependency>

<!-- Anthropic integration -->
<dependency>
  <groupId>dev.langchain4j</groupId>
  <artifactId>langchain4j-anthropic</artifactId>
  <version>1.22.0</version>
</dependency>

No Spring AI, a 2.0.0 GA (junho de 2026) está se consolidando. O milestone 2.1.0-M1 foi publicado em 25 de setembro e o foco está na estabilização do suporte a múltiplos provedores de embedding e na API de avaliação de modelos. O projeto Spring AI Agents é a grande promessa para novembro — segundo a equipe, virá como módulo experimental separado, o que é a abordagem certa para não contaminar o core estável com uma API ainda em formação.
